# KPI Dictionary

| KPI | Formula / Definition | Grain | Business Use |
|---|---|---|---|
| Trial-to-Paid Conversion | Converted users / eligible funnel users | Overall / month / segment | Monetization |
| Funnel Drop-off | Non-converted trial users / trial users | Overall / segment | Leakage diagnosis |
| Time to Conversion | Days between trial start and subscription start | User | Conversion velocity |
| DAU | Distinct active users per day | Day | Engagement |
| MAU | Distinct active users per month | Month | Reach |
| Stickiness | Average DAU / MAU | Month | Usage frequency |
| Retention | Active cohort users / original cohort size | Cohort x month | Product value |
| New Revenue | Revenue in first revenue month | Month | Acquisition growth |
| Expansion Revenue | Revenue after first revenue month | Month | Existing-customer monetization |

## Definition Notes
KPI definitions should remain consistent between SQL and Power BI. Any business-rule changes should be documented before being reflected in dashboards.
