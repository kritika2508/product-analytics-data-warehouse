# Stakeholder Map

| Stakeholder | Primary Questions | KPIs |
|---|---|---|
| Product Manager | Where is the product funnel leaking? Are users returning? | Conversion, activation, retention, stickiness |
| Growth Manager | Which acquisition sources produce stronger outcomes? | Channel conversion, drop-off |
| Customer Success | Which cohorts show weaker sustained usage? | Cohort retention, activity |
| Revenue Team | Where is revenue growth coming from? | New revenue, expansion revenue |
| Leadership | Is growth broad-based and sustainable? | Conversion, retention, engagement, revenue |

## BA Perspective
The same dataset serves different decisions. The dashboard and SQL layer therefore prioritize reusable business definitions rather than isolated analysis.
