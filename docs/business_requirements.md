# Business Requirements

## Objective
Create a decision-ready analytics layer for a subscription SaaS product.

## Functional Requirements
- BR-01: Monitor trial-to-paid conversion.
- BR-02: Analyse funnel stage volumes and drop-off.
- BR-03: Compare conversion by signup month and acquisition channel.
- BR-04: Measure cohort retention over time.
- BR-05: Measure product engagement using DAU, MAU and stickiness.
- BR-06: Separate new revenue from revenue generated by existing customers.
- BR-07: Compare observed outcomes across experiment variants.
- BR-08: Support segment-level investigation using available customer attributes.

## Non-Functional Requirements
- Use consistent KPI definitions.
- Preserve data quality controls between warehouse layers.
- Make analysis reproducible through version-controlled SQL.
- Provide decision-oriented Power BI outputs.
